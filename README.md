# Xueying Luo's M10 Portfolio

A Quarto website with a home page, Case 31 dashboard, CSS/SCSS examples,
and a working project listing. The CEP case study describes my content
research work in progress for PhD Orthodontics.

## Preview the website

Open `M10.Rproj` in RStudio. In the Terminal, run:

```bash
quarto render
quarto preview
```

The R packages used are `tidyverse`, `readxl`, `scales`, and `knitr`.
The rendered website is in `docs/`.

## Case 31 data

Source: Jae Min Jung, [Employees Federal Credit Union Case](https://github.com/jaejungca/case31),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
I adapted the supplied prepared data into dashboard summaries and charts.
The workbook in `data/` is unchanged. Its 128 records differ from the usable
return count in the printed case; the dashboard explains this in Data Notes.
