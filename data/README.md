# Case 31 teaching data

`case31_prepared.xlsx` is an unchanged copy of
`Case 31 Data_efcu_Prepped.xlsx` in the supplied `case31-main.zip`.

Source: Jae Min Jung, *Employees Federal Credit Union Case*.
Repository: https://github.com/jaejungca/case31
License stated in the repository README: CC BY 4.0,
https://creativecommons.org/licenses/by/4.0/.

The dashboard adapts the prepared data into new summaries and charts. It uses
the supplied preparation QMD to interpret labels and recoded fields. The
workbook contains 128 rows and 54 columns. The printed case's count differs;
see the dashboard Data Notes. No rows have been removed or imputed.

This portfolio bundle does not redistribute the scanned textbook case or
the instructor's solution presentations. The source repository contains
those course materials for reference.
